# PulseFit

| Folder | What |
|---|---|
| [api/](api/) | CW1 back end: Python Flask + MongoDB API. See [api/README.md](api/README.md) |
| [frontend/](frontend/) | CW2 front end: Angular application. See [frontend/README.md](frontend/README.md) |

Run the API first (`cd api` then `python app.py`, port 5001), then the front end (`cd frontend` then `npm start`, port 4200).
